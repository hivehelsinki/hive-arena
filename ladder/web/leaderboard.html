Format

  • Runs start every day at {{range $i, $t := .Schedule.Times}}{{if $i}} and {{end}}{{$t}}{{end}} ({{.Schedule.Timezone}}), with the latest tag on the main branch of each team's repository.
  • Each run plays every possible lineup of bots, {{.Schedule.Repeats}} time(s) each, in these formats: {{range $i, $f := .Schedule.Formats}}{{if $i}}, {{end}}{{$f.Map}} ({{$f.Players}} players){{end}}.
  • Seats are random. In each match, points go from 60 (first) to 0 (last), equal flowers share the points of the places they span. A bot that crashes or doesn't join is last.
  • Bots that fail {{.Schedule.MaxFailures}} matches in a row are left out until their next version.
